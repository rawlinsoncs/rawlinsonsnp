# WhatsApp Volunteer Coordination

- **Platform**: Program coordination and shift scheduling among active volunteers are managed via a dedicated WhatsApp group.[^teacher-guidance][^repo]
- **Daily Posts**: Coordinators post daily task digests, schedules, and tag assigned volunteers (e.g., using `@phone_number` mentions) to confirm shift coverage.

Drafting these digests manually is a known automation target — see [WhatsApp Digest Automation](../automation/whatsapp-digest-automation.md).
